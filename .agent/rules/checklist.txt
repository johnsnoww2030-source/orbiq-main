# ۲. بررسی معماری (Clean Architecture)

## ۲.۱ چک‌لیست لایه‌ها

```
┌─────────────────────────────────────────────────────────────────┐
│                     Domain Layer                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ☐ Entities فقط داده + Equatable دارن                         │
│   ☐ Entities هیچ import از Data/Presentation ندارن            │
│   ☐ Repository Interfaces اینجان (abstract class)             │
│   ☐ UseCases اینجان (اگه داری)                                 │
│   ☐ هیچ وابستگی به Flutter/Drift/BLoC نیست                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                      Data Layer                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ☐ Models (Drift Tables) اینجان                              │
│   ☐ DAOs اینجان                                                │
│   ☐ LocalDataSources اینجان                                   │
│   ☐ Repository Implementations اینجان                         │
│   ☐ Mappers اینجان (Model ↔ Entity)                           │
│   ☐ Data Layer به Domain وابسته‌ست (نه برعکس)                  │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│                   Presentation Layer                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ☐ BLoCs اینجان                                               │
│   ☐ Events/States اینجان                                       │
│   ☐ Pages/Widgets اینجان                                       │
│   ☐ BLoC فقط از Repository استفاده می‌کنه                      │
│   ☐ BLoC مستقیم از DAO استفاده نمی‌کنه                         │
│   ☐ UI فقط از BLoC استفاده می‌کنه                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## ۲.۲ Dependency Rule

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   قانون: وابستگی فقط به سمت داخل                               │
│                                                                 │
│   Presentation → Domain ✅                                     │
│   Presentation → Data ❌                                       │
│   Data → Domain ✅                                             │
│   Domain → Data ❌                                             │
│   Domain → Presentation ❌                                     │
│                                                                 │
│   ─────────────────────────────────────────────────────────     │
│                                                                 │
│   چک کن:                                                        │
│   • آیا BLoC مستقیم از DAO استفاده کرده؟ ❌                    │
│   • آیا Entity از Drift import داره؟ ❌                        │
│   • آیا Repository Interface در Domain هست؟ ✅                │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## ۲.۳ بررسی Import ها

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   در هر فایل Domain (Entity, Repository Interface):            │
│                                                                 │
│   ✅ مجاز:                                                      │
│   • import 'dart:...'                                          │
│   • import 'package:equatable/...'                             │
│   • import 'package:dartz/...'                                 │
│   • import از همین لایه Domain                                 │
│                                                                 │
│   ❌ غیرمجاز:                                                   │
│   • import 'package:drift/...'                                 │
│   • import 'package:flutter/...'                               │
│   • import 'package:flutter_bloc/...'                          │
│   • import از Data یا Presentation                             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

# ۳. تست سناریوهای کسب‌وکار

## ۳.۱ سناریو خرید (Purchase)

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ☐ سناریو ۱: خرید محصول جدید                                  │
│      ۱. محصول جدید سریع اضافه کن                               │
│      ۲. فاکتور خرید بزن (۱۰ عدد × ۱۰۰,۰۰۰)                     │
│      ۳. چک کن: موجودی = ۱۰                                     │
│      ۴. چک کن: avgBuyPrice = ۱۰۰,۰۰۰                           │
│                                                                 │
│   ☐ سناریو ۲: خرید مجدد (WAC)                                  │
│      ۱. فاکتور خرید دوم (۱۰ عدد × ۱۲۰,۰۰۰)                     │
│      ۲. چک کن: موجودی = ۲۰                                     │
│      ۳. چک کن: avgBuyPrice = ۱۱۰,۰۰۰                           │
│         (۱۰×۱۰۰ + ۱۰×۱۲۰) / ۲۰ = ۱۱۰                           │
│                                                                 │
│   ☐ سناریو ۳: خرید با هزینه حمل                                │
│      ۱. خرید ۱۰ عدد × ۱۰۰,۰۰۰ + حمل ۱۰۰,۰۰۰                   │
│      ۲. چک کن: قیمت تمام‌شده واحد = ۱۱۰,۰۰۰؟                   │
│         (اگه حمل تقسیم میشه)                                    │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

## ۳.۲ سناریو فروش (Sales)

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ☐ سناریو ۱: فروش ساده                                        │
│      ۱. محصول با موجودی ۲۰، قیمت خرید ۱۱۰,۰۰۰                  │
│      ۲. فروش ۵ عدد × ۱۵۰,۰۰۰                                   │
│      ۳. چک کن: موجودی = ۱۵                                     │
│      ۴. چک کن: costAtSale = ۱۱۰,۰۰۰ (ذخیره شده)               │
│      ۵. چک کن: profit = (۱۵۰-۱۱۰)×۵ = ۲۰۰,۰۰۰                 │
│                                                                 │
│   ☐ سناریو ۲: فروش بیش از موجودی                               │
│      ۱. محصول با موجودی ۵                                      │
│      ۲. تلاش برای فروش ۱۰ عدد                                  │
│      ۳. چک کن: خطا میده ✅                                     │
│                                                                 │
│   ☐ سناریو ۳: فروش بعد از خرید جدید                            │
│      ۱. خرید اول: ۱۰ × ۱۰۰,۰۰۰                                 │
│      ۲. فروش: ۵ × ۱۵۰,۰۰۰ (costAtSale = ۱۰۰,۰۰۰)              │
│      ۳. خرید دوم: ۱۰ × ۱۲۰,۰۰۰                                 │
│      ۴. چک کن: WAC جدید = (۵×۱۰۰ + ۱۰×۱۲۰)/۱۵ = ۱۱۳,۳۳۳      │
│      ۵. چک کن: سود فروش قبلی هنوز ۲۵۰,۰۰۰ هست                 │
│         (چون costAtSale snapshot بود)                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

# ۴. بررسی دیتابیس

## ۴.۱ چک‌لیست جداول

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ☐ Products                                                   │
│      • productUuid (PK, UUID)                                  │
│      • currentStock (بعد خرید زیاد، بعد فروش کم)              │
│      • avgBuyPrice (بعد هر خرید بروز میشه)                     │
│      • serialNumber (Unique)                                   │
│                                                                 │
│   ☐ PurchaseInvoices                                           │
│      • purchaseUuid (PK)                                       │
│      • finalTotal = totalCost + additionalCosts               │
│                                                                 │
│   ☐ PurchaseItems                                              │
│      • purchaseUuid (FK → PurchaseInvoices)                   │
│      • productUuid (FK → Products)                             │
│                                                                 │
│   ☐ SalesInvoices                                              │
│      • invoiceUuid (PK)                                        │
│      • status (PENDING/PAID/CANCELED)                         │
│                                                                 │
│   ☐ SalesItems                                                 │
│      • costAtSale (snapshot از avgBuyPrice)                   │
│      • profit (محاسبه شده)                                     │
│      • invoiceUuid (FK → SalesInvoices)                       │
│      • productUuid (FK → Products)                             │
│                                                                 │
│   ☐ Events                                                     │
│      • eventType (نوع رویداد)                                  │
│      • payload (JSON)                                          │
│      • timestamp                                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

## ۴.۲ بررسی Data Integrity

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ☐ Foreign Keys کار می‌کنن؟                                   │
│      • حذف Product که SalesItem داره → باید خطا بده           │

│                                                                 │
│   ☐ Not Null Constraints                                       │
```

# ۵. Code Review Checklist

## ۵.۱ نام‌گذاری

```
┌─────────────────────────────────────────────────────────────────┐
│                                                                 │
│   ☐ Entity ها با Entity تموم میشن؟                             │
│      مثال: ProductEntity, SalesEntity                          │
│                                                                 │
│   ☐ BLoC ها با Bloc تموم میشن؟                                 │
│      مثال: SalesBloc, PurchaseBloc                             │
│                                                                 │
│   ☐ Repository ها با Repository تموم میشن؟                     │
│      مثال: SalesRepository, SalesRepositoryImpl                │
│                                                                 │
│   ☐ Events گذشته هستن؟                                         │
│      مثال: SaleCreated, ProductLoaded (نه CreateSale)          │
│                                                                 │
│   ☐ States وضعیت هستن؟                                         │
│      مثال: SalesLoading, SalesLoaded, SalesError               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
